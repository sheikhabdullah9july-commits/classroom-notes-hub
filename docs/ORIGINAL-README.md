# Online Classroom Note-Sharing System

A web application where students can upload and share study notes with each other. Admins review notes before they become visible to everyone.

## Features

- User registration and login
- Upload notes (PDF, DOC, PPT, TXT files)
- Admin approval system for uploaded notes
- Like and comment on notes
- Real-time chat between students
- Notifications for likes, comments, and approvals
- Course management

## Technologies Used

- Python 3.9+
- Flask
- SQLite Database
- Bootstrap 5
- Flask-SocketIO for real-time chat

## How to Run

1. Clone the repository
```
git clone https://github.com/saiteja22122212-dotcom/Online-Classroom-Note-Sharing-System.git
cd Online-Classroom-Note-Sharing-System
```

2. Create virtual environment
```
python -m venv venv
venv\Scripts\activate
```

3. Install requirements
```
pip install -r requirements.txt
```

4. Run the application
```
python run.py
```

5. Open browser and go to
```
http://127.0.0.1:5000
```

## Create Admin User

To create an admin account, run:
```
python create_admin.py
```
